## Sıradaki geliştirme adayları

1. S1/S2 için tez kabul ölçütlerini sample testlerinin ötesinde netleştirmek ve host restart / crash senaryolarını ayrı doğrulamak.
2. [`ISagaStateStore`](../src/SagaFlow.Core/Abstractions/ISagaStateStore.cs) sözleşmesine uygun kalıcı adapter ve restart recovery tasarlayıp hata senaryolarıyla sınamak.
3. `maxAttempts` ve `timeout` tanımlarının yürütüm politikasını karara bağlayıp otomatik retry/timeout geçişini ayrı testlerle doğrulamak; bugün bu alanlar tam yürütüm sağlamıyor.
4. Gerçek host ve tarayıcı üzerinde dashboard canlı güncellemesini, ardından domainler arası runtime görünürlüğü ihtiyacını doğrulamak.
5. Warehouse bekleyen kararının ve Return iş kaydının host restart sonrası kaybını gidermek; refund sonrası restock/notification hatası için manuel uzlaştırma politikasını tanımlamak.

Bunlar tamamlanmış özellikler veya değiştirilmiş mimari kararlar değildir; mevcut farklardan türetilmiş çalışma adaylarıdır.
