1. S1/S2 için tez kabul ölçütlerini sample testlerinin ötesinde netleştirmek ve host restart / crash senaryolarını ayrı doğrulamak.

4. Gerçek host ve tarayıcı üzerinde dashboard canlı güncellemesini, ardından domainler arası runtime görünürlüğü ihtiyacını doğrulamak.
5. Warehouse bekleyen kararının ve Return iş kaydının host restart sonrası kaybını gidermek; refund sonrası restock/notification hatası için manuel uzlaştırma politikasını tanımlamak.
